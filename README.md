# 1 задание. Советы по улучшению сайта

- Первое, на что обратила внимание, — **уровень яркости**. Зайдя вечером на сайт, увидела, что не хватает тёмной темы. Или можно обойтись более спокойными тонами фона, так как такой яркий белый свет режет глаза.

- **Лента информации** просто меняет местами три объекта, как нажимаешь внизу переключатели. Это кажется бесполезным и только мешает, так как они просто переставляют объекты местами.

  ![image](https://github.com/user-attachments/assets/284ad1f7-3854-49c2-a70d-593fb6de9583)

- Тут лучше немного **поправить формулировки**, например «и другие курсы». Иначе каждый раз, как будет меняться количество курсов, придётся вручную поправлять ссылку (не нашла какой-либо JS, который пишет точное количество курсов). Плюс такая большая кнопка теряется под формой — кажется, что это не кликабельная ссылка.

  ![image](https://github.com/user-attachments/assets/be6e5e60-7e9b-4196-bc44-b87a74f8cc1b)

- Сайт выглядит **пустоватым**. Можно на фоне поставить шестерёнки, маленькие ракеты и так далее. Чисто добавить дизайна, чтобы выглядело более презентабельно для родителей и детей.

- Когда включаешь доступное видео, **включается реклама с RuTube**. Ждать 2 рекламы не хочется, её нельзя пропустить. Лучше загрузить видео на что-то наподобие Vimeo.
